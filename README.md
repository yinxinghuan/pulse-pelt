# Pulse Pelt / 脉冲星绒

一款面向 AlterU 手机端的原创 Three.js 触屏视觉玩具。单指在虹彩纤维星体上播种局部波纹，六个分离触点会形成稳定共振；双指可旋转和缩放观察最终星体。

## 原创与参考边界

本项目是在审计 `threejs-challenge-0` 时发现其没有公开许可证后重新立项的原创作品。项目没有复制或分发该仓库的代码、shader、纹理、参数或素材，也不声称复刻其视觉实现。唯一保留的问题空间是通用抽象概念：“球形表面响应触摸产生局部形变”。

## 开发

```bash
npm install
npm run dev
npm run build
```
