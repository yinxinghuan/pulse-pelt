# 脉冲星绒：需求文档

## 1. Overview

《脉冲星绒》是一款 30–90 秒的手机竖屏视觉玩具：玩家用单指在一颗由发光三角纤维构成的星体表面播种波纹，形成 6 个彼此分离的共振点，让星体进入稳定绽放状态。

目标玩家是在 AlterU 信息流中短暂停留、希望立刻触摸并得到视觉回馈的用户。体验没有倒计时、生命或排行榜；完成后的星体保持可观察，并允许立即重织。

本作只参考“可触摸球形表面产生局部形变”这一抽象概念。不得复制 `emmelleppi/threejs-challenge-0` 的代码、shader、纹理、参数、模块结构或素材，也不得把本作描述为该项目的视觉复刻。

## 2. Visual Design

- 目标尺寸为 `390×844`，最低验收尺寸为 `320×568`，竖屏优先。
- 视觉主体是一颗占可用画面宽度约 `78%` 的深色虹彩纤维星体；背景为深靛色空间雾和低密度星尘。
- 球面由 `1080–1680` 枚三棱纤维组成，纤维随触点产生向外波峰、回落和方向偏转。
- 每个有效共振点留下一个带独特色相的光斑；第 6 个共振点触发全局协调波与核心亮度提升。
- 标题、简短隐藏手势提示、六段式进度标记和完成操作是唯一常驻界面；不使用卡片式 HUD。
- 所有功能图标使用同一套 `2px` 圆角线性 SVG；禁止 Emoji。
- 具体颜色、排版、材质和动效合同见 `doc/visual.md`。

## 3. Game Mechanics

- 初始状态为低成本 sleeping state，不创建 WebGL renderer；第一次主动触摸后创建场景。
- 默认高档使用 `1680` 根纤维、像素比上限 `1.5`；窄屏或低性能档使用 `1080` 根、像素比上限 `1.25`。
- 球体基础半径为 `1.32` 世界单位，纤维基础高度为 `0.30`，三棱截面半径为 `0.040`。
- 指针通过不可见半径 `1.38` 的球体做 raycast；命中后以命中方向创建波源。
- 每个波源的波峰在 `180ms` 到达局部峰值，`980ms` 衰减到静态光斑；动态影响半角约 `28°`。
- 有效共振点必须与已有点保持至少 `24°` 的球面夹角；过近触摸只产生即时波纹，不增加进度。
- 最多保留 `6` 个静态共振点和 `8` 个短期动态波源；超出后淘汰最老的短期波源。
- 第 6 个有效点触发 `1400ms` 的全局协调波，核心亮度由 `0.32` 提升至 `1.0`，纤维色相混合强度提升 `45%`。
- 完成后不冻结相机；玩家仍可触摸制造局部波纹。点击重织会在 `650ms` 内收束回初始星体。
- 页面不可见或交叉可见比例低于 `0.15` 时暂停 RAF；恢复可见后按真实时间继续，不补算离屏帧。

## 4. Controls

- 单指按下球面：同帧产生压入光环与纤维形变；若距离已有共振点足够远，则锁定一个新共振点。
- 单指拖过球面：每移动至少 `22px` 追加短期波源，频率上限为每 `70ms` 一个。
- 双指拖动：旋转观察星体；水平移动控制方位角，垂直移动控制俯仰角，俯仰限制为 `±1.05rad`。
- 双指捏合：在响应式基础距离的 `0.82–1.25` 倍之间缩放。
- 桌面鼠标拖动空白区域：旋转相机；点击球面播种波纹。
- 键盘 `R`：重织；键盘 `M`：切换静音。
- 所有触控目标至少 `44×44 CSS px`，使用 Pointer Events；画布设置 `touch-action: none`。

## 5. Win / Lose Conditions

- 没有失败条件。
- 当 6 个有效共振点全部锁定时完成本轮。
- 完成状态显示星体名称“共振已定 / Resonance held”、本轮生成的六色色谱，以及“重织 / Weave again”按钮。
- 完成层不得遮挡球体中心或模糊场景；最终画面持续可旋转和触摸。
- WebGL 不可用或初始化失败时显示错误说明和“重试 / Retry”按钮；失败状态不得留下空白 Canvas。

## 6. Sound Effects

- 首次唤醒：`180–420Hz` 正弦上滑，`320ms`，快速起音、指数衰减，音量 `0.10`。
- 普通波纹：以共振点序号映射 `220–520Hz` 的正弦/三角混合音，`160ms`，音量 `0.055`，最多同时 `4` 声部。
- 锁定共振点：在普通音上增加高五度泛音，`280ms`，音量 `0.075`。
- 完成：六个音高以 `55ms` 间隔进入，随后 `880ms` 柔和和弦收束，峰值音量 `0.12`。
- 重织：`420–170Hz` 下滑正弦，`300ms`，音量 `0.06`。
- AudioContext 仅在用户首次主动输入后创建；静音或音频失败不阻塞视觉反馈。
