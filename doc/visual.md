# 脉冲星绒：视觉与界面系统

## 1. 视觉论点

把星体做成一件可触摸的“活体光纤雕塑”：玩家的手势不是在 UI 上填进度，而是在球面留下会彼此呼应的真实形变。最终记忆点是一颗由六个触点共同点亮、仍可自由观察的虹彩星体。

原创边界：不使用参考仓库的灰白胶囊表皮、四颗自动环绕玻璃球、灰色摄影棚背景、蓝噪声纹理、折射采样方法、shader 表达式或参数。视觉从深色空间、三棱纤维、玩家直接触摸和六点协调波重新建立。

## 2. 构图与相机

- 竖屏透视相机使用 FOV `42°`，基础距离按 `clamp(5.34 / aspect, 8.8, 11.8)` 计算，主体中心位于画面高度 `49%`。
- `390×844` 下星体直径约 `305px`；`320×568` 下约 `244px`，不因外部访客栏永久下移。
- 标题位于顶部安全区内，最大宽度 `calc(100% - 40px)`；进度六点沿标题下方水平排列。
- 完成操作贴近底部安全区，但保持星体下缘至少 `28px` 可见空间。
- platform-layout 是主构图；external-guest 只验证覆盖层可用性。

## 3. 色彩系统

- `void-950 #070812`：外层背景。
- `void-800 #11152A`：空间雾。
- `fiber-base #25345C`：未激活纤维暗部。
- `cyan #67F4FF`、`violet #A68CFF`、`magenta #FF6EC7`、`amber #FFD27A`：球面虹彩与六点色谱。
- `text-primary #F4F3FF`、`text-muted #A8ADC9`。
- `danger #FF7D91`：仅用于初始化错误。
- 普通文字对背景至少 `4.5:1`；状态不能只靠颜色，进度点同时改变尺寸和轮廓。

## 4. 排版

- 标题使用系统无衬线重字重：`Inter, "SF Pro Display", "PingFang SC", sans-serif`，`30/31px`，字距 `0.02em`。
- 英文标题可用全大写小尺寸 `11/14px` 作为眉题；中文/英文主标题均不超过两行。
- 正文与提示 `16/23px`；非交互 HUD 最小 `12/16px`。
- 不加载外部字体，避免首帧布局跳动。

## 5. 形状、材质与光

- 球面元素统一为细长三棱纤维，根部暗、尖端亮；不使用圆润胶囊阵列。
- 内核是半透明深靛球体，边缘有轻微 Fresnel 辉光。
- 纤维材质采用程序化视角虹彩、顶端渐亮和触点色谱混合，不使用照片、matcap 或噪声贴图。
- 光来自左上冷光与右下柔和品红补光；不使用写实摄影棚地面或硬阴影。

## 6. 素材规则

- 游戏运行素材全部程序化生成；无外部图片、模型、纹理、HDR、LUT 或音频文件。
- 正式海报必须由 Aigram transit 生图接口生成，并在 `doc/poster-source.md` 记录请求。
- 海报不得使用游戏截图、Canvas、CSS 或 SVG 栅格化结果。

## 7. UI 与图标

- UI 不使用卡片容器；文字和按钮直接悬浮在空间背景上。
- 重织、静音和重试使用同一套自绘 `2px` 圆角线性 SVG，`24px` 图形置于至少 `44px` 触控面。
- 主按钮使用细线轮廓和清晰文字；按下时缩放至 `0.96` 并提升描边亮度。
- 睡眠态使用共享 Material `touch_app` 语义的幽灵手轮廓，演示调用与玩家相同的球面波纹函数。

## 8. 动效与特效

- 唤醒：背景雾先显，星体在首个真实渲染帧后从 `0.92` 缩放至 `1`，`520ms`。
- 普通触摸：`0–180ms` 压入和尖端点亮，`180–980ms` 环形波扩散并恢复。
- 锁点：局部光斑在 `360ms` 内收束为稳定节点，伴随一次外扩细环。
- 完成：六点依次点亮，随后全局协调波跨越球面，`1400ms` 完成；不使用屏幕震动。
- 重织：节点色彩向内核收束，`650ms` 后清空。
- `prefers-reduced-motion` 下关闭背景漂移和全局旋转，只保留 `50%` 振幅的必要局部形变。

## 9. 参考转译

- 参考只提供“球形触觉表面”这一问题空间。
- 原作的被动自动形变改为玩家直接播种；灰白工业表面改为深色虹彩纤维；自动环绕物体改为六个玩家留下的稳定节点。
- 原作单纯观看改为自定步调的共振闭环，且完成后保留最终雕塑。
- Three.js 的 InstancedBufferGeometry、Raycaster 与标准数学分布作为公开通用技术使用；具体数据结构、shader 和参数重新设计。

## 10. 反模式

- 禁止灰白摄影棚、胶囊密铺外观和四颗自动环绕玻璃球。
- 禁止复制或翻译无许可仓库的 GLSL、纹理、常量、组件结构和函数命名。
- 禁止倒计时、分数、排行榜、三条命或强制失败。
- 禁止玻璃卡片、霓虹按钮堆叠、功能 Emoji、长说明和遮挡主体的结算弹窗。
- 禁止为 external-guest 访客栏永久增加顶部 padding 或缩小星体。

## 11. 垂直切片验收

- `390×844` 与 `320×568` 首屏都能在 `2s` 内理解“触摸球体”。
- sleeping state 在 JS/Three 加载前就有主题画面，唤醒后直到有意义首帧期间不出现空白。
- 单指触摸必须让球面本体产生可见形变；幽灵手演示也调用同一输入路径。
- 六个分离触点可完成闭环，完成层不遮挡星体，重织可在 `1s` 内回到可玩状态。
- 双指旋转/捏合与单指塑形不冲突。
- 离屏、隐藏和完成静止状态不会继续无意义消耗 GPU。
- WebGL 初始化失败有可见错误与重试路径。
